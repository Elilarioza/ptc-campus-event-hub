# PTC Campus Event Hub

### A Web-Based Campus Event Management and Registration System

**Institution:** Pateros Technological College  
**Course:** Integrative Programming and Technologies  
**Section:** BSIT - 4K  
**Instructor:** Prof. Mary Grace Lopez

## Project Description

PTC Campus Event Hub is a web-based system designed to help students discover campus events and manage event registrations. It also allows administrators to manage events, categories, venues, student registrations, attendance, and announcements.

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP
- phpMyAdmin

## Main Features
- Student Registration and Login
- Student Dashboard
- Event Browsing and Calendar
- Event Registration
- My Registrations
- Announcements and Notifications
- Student Profile Management
- Admin Dashboard
- Event and Category Management
- Venue Management
- Registration and Attendance Management

## Installation and Setup

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into `C:\xampp\htdocs\`.
4. Open phpMyAdmin.
5. Create the required database.
6. Import the project's SQL database file.
7. Check the database connection settings.
8. Open the browser and visit:

`http://localhost/ptc-campus-event-hub/`
